# MANDATE — a Downing Street simulation

Browser game: become UK Prime Minister, survive up to ten years of maths.
A monthly macro-economy (growth, inflation, Bank rate, gilt-market trust),
spatial-politics party factions, cube-law elections, wars with support-decay
curves, scandals, budgets, and a legacy score ranked against every post-war PM.

Play: https://felixgbondatpropnition.github.io/mandate/

- `index.html` — the whole game (no build, no dependencies)
- `test.js` — headless engine stress test (`node test.js`, 120 random premierships)

Daily Crisis mode seeds the day's date — everyone gets the same events.
